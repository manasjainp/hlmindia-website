    Security & Settings

    🔒 Old Voucher Edit Protection

    Require an admin password to edit or delete any voucher created on a previous date.

    💾 Backup & Restore

    All data is stored only in this browser. If you clear browser data, switch devices, or reinstall, everything is lost unless you have a backup file. Download one regularly (e.g. at day close).

    💳 Payment Modes

    Every Jama/Nava entry records how the money moved. Manage the list of modes available in the entry form here.

    📅 Financial Year Management

    —

    Starting a new financial year carries forward every ledger name (customers, suppliers, expense heads, bank/cash accounts) so they're ready to use immediately. It resets cash-in-hand and every party's outstanding balance to zero from that date — no past entries are ever deleted.

    Financial YearReset DateStarted On

    ⚠️ Danger Zone

    Permanently erase every entry, ledger, balance, and setting from this browser. This cannot be undone unless you have a backup file.

    ☁️ GitHub Data Sync (Advanced)

    Store all application data in a private GitHub repository instead of this browser's local storage. WARNING: This is an advanced feature. Your Personal Access Token will be stored in this browser. Anyone with access to your browser could potentially steal this token. Use a private repository and a token with minimal permissions.

    🗑️ Confirm Factory Reset

    This is the final step. Enter the reset password to permanently erase all entries, ledgers, balances, backups history and settings from this browser.
